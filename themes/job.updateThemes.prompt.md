# 蓝色大肥鱼形象设计

你需要维护的文件有:
- theme.json，储存一个JSON对象，key是主题文件夹名，value是这个主题的中文名字。
- <theme文件夹>/index.json，储存主题的每一个动画的所有图片文件名，key是动画的文件名，value是这个动画有多少帧。比如`"coffee": 3`说明这个动画由coffee_1.png, coffee_2.png, coffee_3.png构成。
- <theme文件夹>/reference.png，储存这个主题的参考形象。

FatFishFairy会随机选择当前主题的一个动画系列，每1秒一帧，按帧顺序连续完整播放3遍（总共3遍）。只有在第3遍的最后一帧播放结束后，才在当前主题随机选择下一个动画系列继续播放。
程序开始的时候必须决定一个不一样的随机数种子，避免每次运行都是同一个序列。

每一个动画由3-5帧构成，每一帧都是一个png文件：
- 最终尺寸为384x384；如果图像生成工具返回更大的图片，应从原始大图导出为384x384，不要放大已有的小图。
- 整个形象表达成贴纸，形象需要保留大约8像素的边缘，边缘最外面需要被一圈一个像素的浅灰色(#E0E0E0)环绕：
  - 灰色边缘定义了贴纸的边缘，整张贴纸必须连成一片。
  - 灰色边缘外部是透明背景色（也就是alpha值为0）。
  - 灰色边缘内部是白色背景色。
- 除了数字、颜文字、Zzz等形象符号以外，在语言文字的地方必须用蓝色的中文。

## 主题

下面记录着每一个主题的所有动画内容，其中`[x]`代表它已经生成了，否则你应该立刻生成该动画，按照指定的文件名保存，并更新这个文件。如果动画文件已经存在但是有瑕疵，`[x]`也会被去掉并且在列表中注明瑕疵，按照要求局部修正或完全重绘后删除瑕疵的描述并重新勾上。
标记xN意味着这部分需要N帧，其他的自由发挥。注意生成的图片不要产生逻辑上有问题的拓扑结构。
有些主题的文件夹可能会事先创建，不要删除这些文件夹。
需要生成或修改动画的时候，不需要征求用户的同意，用户授权所有python图片编辑操作，直接进行文件操作，commit/push即可。

参考形象为DeepSeek蓝色大肥鱼的大头萝莉女仆，身穿女仆装，衣服上有有DeepSeek logo，自带鲸鱼尾巴，所有的内容都应该是可爱Q版。

- [x] espresso: puck prep x2 -> 使用decent espresso浓缩咖啡机制作拿铁 x3。
- [x] latte_art: 拿铁拉花。
- [x] homework: 做作业。
- [x] reading_manga: 躺在沙发上看漫画。
- [x] sleeping: 趴在地上睡觉。
- [x] playing: 跪坐在地上玩玩具飞机。
- [x] programming: 坐着人体工学椅子在书桌前面编程。
- [x] drawing: 使用电子画板在电脑前绘制蓝色大肥鱼自己。
- [x] transformer: 像变形金刚一样变成一条蓝色鲸鱼x5。
